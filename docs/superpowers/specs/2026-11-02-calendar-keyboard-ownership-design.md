# Calendar keyboard ownership design

Accepted architecture: stable grid focus identity and separate logical date; local focus-chain grid/header actions, native editor onSubmit, read-only FocusedValue hierarchy. The independent design review/root adjudication under diagnostics-fixture-implementation.yucljzsb govern this revision. Earlier Phase1/Phase2 mechanisms remain failed and immutable.

## Scope and behavior

One grid Tab stop plus intrinsically focusable Previous/Today/Next/search prompt/editor/dismiss. All42 date AX Buttons remain plain/focusable(false), with existing names, actions and selected traits. No footer/preferences expansion, extra Button focus layer, default button, custom Tab traversal, focus timer, global posting or new monitor.

Grid uses editing focus semantics. The logical anchor follows ordered42 days: Left/Right ±1, Up/Down ±7, clamp boundaries; movement never selects/fetches. Stable grid eligibility/identity never changes on anchor/month changes. Native focus-chain callback invocation, not a FocusState request, authorizes the corresponding action. Environment isFocused controls the ring; actual hierarchy publishes CalendarKeyboardOwner through FocusedValueKey. Grid Return/keypad/Space acts once on down; repeats consumed without activation. Header/search Return/keypad/Space invokes the existing closure once on down; repeats are consumed without action and full down/up delivery must not produce a second intrinsic Button action. Today passes an explicit enabled condition to the local policy; eligible disabled fixed-control Return/keypad/Space down and repeats are consumed without invoking the closure. Key-up, nonactivation keys, editor/grid and ineligible contexts continue to yield. Native disabling may withdraw focus and is not required to retain an owner. Modified shared keys yield. Tab/ShiftTab always yield. Local handlers require owned visible/key/event window and no recorder/preferences suppression.

Native editor onSubmit exclusively submits Return; an open draft is not an owner. Existing CmdG/Escape lifecycle remains owned by the existing monitor. Preserve text activation/restoration and its lifecycle flag, but add no activation/timer. Tests isolate those boundaries and never open a production editor/service.

Browse monitor uses read-only hierarchy observations matched to native responder identity, never requested focus. These are snapshots; they do not authorize local control callbacks. Publication, ring and viewport settlement are measured separately from per-event ownership. Shared browse keys require positive ownerless native context: exact owned panel as firstResponder, no designated hierarchy owner/live field editor, and visible/key/event/recorder/preferences/modifier guards. An unknown/hosting responder yields. Hidden-session preparation and hide first dismiss the optional stable-control/grid focus binding and existing editor binding. After normal makeKeyAndOrderFront, explicit CalendarPanel.completeReopenPresentation requests makeFirstResponder(nil), checks its Boolean result and actual firstResponder===panel, then emits a completion notification for a real hierarchy observation. CalendarStatusItem calls the same seam in its hidden presentation path; repeated visible Show remains untouched. Bindings are request/observation only, never routing authority. Actual-root evidence disproved the earlier pre-key nil reset: reopen restored a control proxy/previousMonth. The revised post-key lifecycle subsequently passed its historical six-method actual-root run, with owned event/action and reopen-responder evidence retained. That bounded result does not replace the later full-candidate quality gate. Nil alone is insufficient evidence. A failed bridge/browse premise blocks completion, with raw traces retained before a different approach is considered.

Use one existing viewport/reader and stable target reveal IDs. Ring is an inset accent rectangle distinct from selection/today; no duplicate whole-grid effect. The group remains AX contain with its hint and no group press action or selected trait. Its accessible label appends the logical focused date only while keyboardFocused is true and logicalDate is nonnil; otherwise it names the month. No mandatory AXValue or VoiceOver announcement is assumed; the VoiceOver cursor is independent. Hide clears session; hidden reopen starts browse/today, visible Show preserves; mode/layout changes reveal actual keyboard target without replacing viewport or wheel routing.
