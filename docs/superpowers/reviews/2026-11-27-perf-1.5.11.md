# Release readiness review — v1.5.11 (build 48)

**Scope:** Performance batch. (1) Consolidate 5 duplicate `Date.FormatStyle` instances into one shared `TimeFormatter` (`shortTime` + `clockOnly`) — output-identical refactor, no behavior change. (2) `NextMeetingFeature.refresh` skips a redundant EventKit fetch on a same-day refresh (panel close / wake / clock change) by reusing cached events and recomputing the next meeting from cache. (3) A distinct `.calendarChanged` action that ALWAYS fetches, wired to `EKEventStoreChanged`, so same-day calendar edits are never missed. Local only, no network.
